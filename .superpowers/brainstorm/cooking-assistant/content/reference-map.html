《教妹妹开车》里值得偷的 6 个机制

核心不是驾驶，而是「你只能出嘴，她握着方向盘」这种无能为力又必须开口的关系。做饭可以原样移植，只是角色换位。

《教妹妹开车》
搬到做饭助手
PERSPECTIVE
副驾驶视角
你被固定在副驾驶，握方向盘的是她，你只能靠说话影响结果。
→
PERSPECTIVE
灶台边的她
她碰不到你的锅，只能看着你、提醒你。她的手是空的 —— 这个设定让“指导”变得合理，也让人心软。
INPUT
实时语音对话
直接喊话，妹妹实时听取并反应；网速和口音都会影响她听不听得懂。
→
INPUT
语音 + 文字双通道
原型先用文字与快捷短语；语音按钮预留位置，等接上 ASR 再开。她“听不懂”时的追问也是演出的一部分。
FAILURE
妹妹会犯错，你得预判
她手忙脚乱，你必须在她出错前喊停。慢半拍就撞了。
→
FAILURE
她盯着你的火候
计时超时、步骤停留过久、顺序做错，她会先出声：“火大了，关小一点。”原型里用计时器与步骤状态就能模拟。
PROGRESSION
练习场 → 真实道路
从空场地开到城市、高速，需要教的东西越来越多。
→
PROGRESSION
新手菜 → 家常 → 硬菜
煎蛋、番茄蛋汤起步；进阶到炒菜、红烧；她教得越来越细，也更敢吐槽你。
EVENT
突发事故
行人、爆胎、急刹 —— 每一秒都可能超出预期。
→
EVENT
厨房突发
糊锅、油溅、忘关火、盐放多了。她表情和语气会立刻变，给出补救方案而不是重做。
CHARACTER
手忙脚乱但可爱的她
会紧张、会顶嘴、会因为你吼她而闹别扭 —— AI 的不完美被写成了角色魅力。
→
CHARACTER
不完美才像人
她会记错你上次说“太咸”，会因为你夸她而尾巴翘起来，也会在你手忙脚乱时叹一口气。

还有一个没列进去的：HUD。驾驶游戏用仪表盘呈现速度与危险，我们对应的是灶台面板 —— 火候、计时、当前步骤。
